# Звіт до лабораторної роботи

* **Дисципліна:** Архітектура вебзастосунків
* **Номер і тема роботи:** Лабораторна робота №1 — Дослідження та розгортання вебсторінки (Dynamic Neon Cyberpunk)
* **Автор:** Мамонтов Євген (група ІН-41/1)

## Короткий опис проєкту
Розроблено адаптивну профіль-сторінку з використанням ефектів CSS Glassmorphism, інтерактивними елементами на JavaScript, підтримкою динамічних стилів та локального сховища (Local Storage) для збереження ідентифікатора сторінки (PageID). У процесі виконання проведено аудит за допомогою Chrome DevTools.
